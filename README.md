# DrivePanel app store for Runtipi

This is a small [Runtipi](https://runtipi.io) app store with one app: **DrivePanel**, your own lightweight Google Drive at home (Raspberry Pi or any Linux PC).

> **Languages / Idiomas:** DrivePanel is in Spanish right now. **English is coming very soon**, and more languages will follow later if people ask for them.
> Ahora DrivePanel está en español. **El inglés llegará muy pronto**, y más adelante otros idiomas si la gente los pide.

## How to add it

1. In Runtipi, open **Settings → App stores** (or **App store → Manage stores**).
2. Add a new store with this URL:

   ```
   https://github.com/pctecnikk/drivepanel-runtipi
   ```
3. Search for **DrivePanel** in the App store and install it.

After installing, open DrivePanel and register: **the first user becomes the administrator.**

## Tienda de DrivePanel para Runtipi (español)

1. En Runtipi entra en **Ajustes → Tiendas de apps** y añade esta dirección: `https://github.com/pctecnikk/drivepanel-runtipi`
2. Busca **DrivePanel** en la tienda e instálala.
3. Abre DrivePanel y regístrate: **el primer usuario es el administrador.**
